# Branchenportale-Mapping

Mapping von Branchen zu den jeweils relevanten Branchenportalen im deutschen Markt. Wird vom Skill in Phase A genutzt, um die Schema-Vorschläge zu generieren — der Stratege bestätigt oder ergänzt.

Diese Liste ist **wachsend** — bei jeder neuen Branche, die wir bedienen, kann hier ergänzt werden. Die Liste sollte mit Standdatum gepflegt werden.

**Stand:** Mai 2026 — initiale Version

## Wie diese Liste zu lesen ist

| Spalte | Bedeutung |
|---|---|
| **Portal** | Name + Haupt-URL |
| **Typ** | Bewertungsportal / Verzeichnis / Marktplatz / Review-Aggregator |
| **Relevanz** | hoch / mittel / niedrig — wie wichtig dieses Portal in dieser Branche typischerweise ist |
| **Reach** | Geo: lokal / regional / national / DACH |
| **Touchpoint-Charakter** | Ist das Portal eher *Lead-generierend* (Anfragen kommen direkt rein) oder *Reputation* (Bewertungen beeinflussen die Wahl der Kunden) |

## Wie der Skill die Liste nutzt

1. **In Phase A**: Aus `meta.json.branche` die passende Sektion oben suchen. Wenn keine direkte Übereinstimmung: nächst-ähnliche Sektion + branchenübergreifende Liste.
2. **Portale mit Relevanz "hoch"** werden automatisch in das Schema aufgenommen.
3. **Portale mit Relevanz "mittel"** werden vorgeschlagen, Stratege bestätigt im Review.
4. **Portale mit Relevanz "niedrig"** nur erwähnen, wenn der Stratege explizit nach Vollständigkeit fragt.

## Erweiterung der Liste

Wenn eine neue Branche bedient wird, die hier fehlt:

1. Neue Sektion im passenden Hauptkapitel anlegen (Gesundheit, B2B, etc.)
2. Recherche der gängigen Portale (Web Search "branchenportale [Branche] Deutschland")
3. Mit Stratege validieren
4. Eintrag mit Stand-Datum kommentieren

Die Liste lebt — und sollte regelmäßig kuratiert werden (z. B. jährlich überprüfen, ob Portale noch aktiv sind, neue dazugekommen).
